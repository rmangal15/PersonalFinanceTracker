# Personal Finance Tracker

## About the Project
Personal Finance Tracker is a Java console-based application that helps users manage their income and expenses.

## Features
- Add Income
- Add Expenses
- View All Transactions
- Monthly Income and Expense Summary
- Calculate Remaining Balance
- Filter Transactions by Category
- Filter Transactions by Date
- Export Transactions to CSV
- Save and Load Transaction Data

## Technologies Used
- Java
- Object-Oriented Programming
- File Handling
- CSV Files

## How to Run
1. Install Java JDK.
2. Open the project in Visual Studio Code.
3. Open PersonalFinanceTracker.java.
4. Run the program.
5. Follow the menu displayed in the terminal.
